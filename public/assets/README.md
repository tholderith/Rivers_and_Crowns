# Game assets

Generated by the tools in `tools/` from the raw images in `art/incoming/`. Don't edit by hand:
rerun the tools instead.

| Folder | Contents |
|---|---|
| `sprites/<ID>/` | One transparent WebP per object or pose, numbered in reading order (left to right, top to bottom). Unit sheets hold the four poses: ready, attack, reload or move, defeated. |
| `portraits/<ID>/` | Hero portraits, cut out from their navy backgrounds. |
| `textures/` | Seamless 512 px tiles: terrain T-01 to T-08 (T-03 road tiles top to bottom only) and interface textures I-06 to I-08. |
| `towns/<town>/` | `base.webp` (empty plots) plus one WebP per building, all 1920 px wide when stacked. `layers.json` gives each layer's position as fractions of the base, the draw order, and which upgrade replaces or adds to which building. |
