Art List

Every image the prototype needs, plus what comes after. Each card has a complete prompt for ChatGPT image generation that you can paste as is. P0 is needed for the prototype, P1 is wanted for the prototype, and P2 comes after it.

How to run it

Set up once

  1. Create a ChatGPT Project called "Rivers & Crowns art" and upload the reference images listed below as project files.
  2. Generate S-01 Style anchor first. Regenerate it until you love it, then add it to the project as reference A0.
  3. Keep one chat per batch (for example "French units") so the model keeps its context.

For every image

  • Attach the references named on the card before pasting the prompt.
  • If one object in a sheet is wrong, ask for an edit to that object only. Don't regenerate the whole sheet.
  • Download as PNG and name the file with the card ID, for example U-FR-03.png.

What I do with them

  • Cut sheets into single sprites, remove backgrounds, and match scale and baseline.
  • Split town paintings into building layers by comparing the full and empty versions.
  • Build all UI, numbers and text in code.
